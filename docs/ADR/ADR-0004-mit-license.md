# ADR-0004 — Licença MIT

- **Status:** Adotada
- **Contexto:** Os arquitetos desejam código aberto, mas não querem restringir uso interno.
- **Decisão:** Licença MIT para todo o repositório (source, docs, exemplo).
- **Consequências:** + adoção ampla; - nenhuma restrição de uso comercial (evitar restringir licenças futuras de sub-pacotes).
